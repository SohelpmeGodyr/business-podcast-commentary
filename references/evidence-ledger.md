# 证据台账

在通读逐字稿后、正式起草前使用本参考文件。先用内容覆盖地图防遗漏，再用主张台账管理证据；两者不能互相替代。内部表格不默认展示给读者，详细溯源放在文章附录。

## 内容覆盖地图

内容覆盖地图回答“陌生读者理解整期内容需要什么”，不是只找可证伪的承重断言。

| 字段 | 记录内容 |
|---|---|
| 时间段 / 位置 | 逐字稿时间戳、段落或章节。 |
| 主题 | 这一段在讨论什么问题。 |
| 关键主张 | 嘉宾的判断、建议或结论。 |
| 论证材料 | 案例、数字、因果链、类比和亲身经历。 |
| 理解条件 | 陌生读者必须知道的背景、术语和前因后果。 |
| 限定与反方 | 嘉宾自己的边界、犹豫、例外、反作用或他人异议。 |
| 行动信息 | 方法、步骤、决策建议或观察指标。 |
| 重要性 | 高 / 中 / 低，并写理由。 |
| 正文去向 | 计划进入的章节；不纳入时写删减理由。 |

高优先级条目必须进入正文，除非与其他条目实质重复。完成初稿后反向核对：每个主要主题、关键例子、限定条件和行动步骤是否有明确去向。

## 主张台账

| 字段 | 记录内容 |
|---|---|
| 主张 | 可被证伪的商业断言，而非议题标签。 |
| 提出者 | 提出该断言的说话者或来源。 |
| 位置 | 经营者、投资人、平台、监管者、客户、评论者或其他相关角色。 |
| 来源 | 时间戳、页码或公开来源链接。 |
| 证据标签 | 直接陈述、嘉宾估算、公开核验、编辑推演或待验证。 |
| 机制 | 原因 → 机制 → 结果。 |
| 前提 | 该主张成立所需的条件。 |
| 反例 | 最强替代解释、约束或反证案例。 |
| 信号 | 能增强或削弱该主张的可观察指标或事件。 |
| 可信度 | 高、中、低，并给出一句理由。 |

## 数字主张台账

| 字段 | 记录内容 |
|---|---|
| 指标 | 使用指标拥有者的准确定义。 |
| 数值与单位 | 保留币种、百分比、用户数、分钟等单位。 |
| 时间与地域 | 记录统计周期和市场范围。 |
| 经济层级 | 消耗、GMV、总收入、净收入、毛利、净利、现金流、抽成率或分成。 |
| 分子 / 分母 | 报告比例或利润率时必须同时写明。 |
| 来源与状态 | 嘉宾估算、公开财报、平台公告或编辑计算。 |
| 可比性 | 说明能否与相邻数字直接比较及理由。 |

## 可信度指引

- **高**：一手公开来源，或多个独立来源直接支持同一口径和同一期间。
- **中**：可信的一线经营者提出，但数值或因果关系尚无独立验证。
- **低**：宽泛预测、个案、定义不清的数据，或存在未化解利益冲突的主张。

## 隐性信号清单

| 字段 | 记录内容 |
|---|---|
| 编号 | 与正文 callout 的对应关系。 |
| 承重叙事 | 该信号依附的承重主张或行为，附逐字稿时间戳。 |
| 档位 | `可判定` / `存在但不可判定`。 |
| A / B / C | 显性引导 / 隐性顾虑 / 深层指向；未判定档写并列候选解读。 |
| 支撑维度与特征 | 六维中哪几维、逐字稿中的具体语言特征位置。 |
| 反方解释 | 同一证据的竞争性解读。 |
| 可证伪条件 | 什么新证据会推翻此推演。 |

## 情景卡片

| 情景 | 驱动状态 | 触发条件 | 领先信号 | 受益者 / 受损者 | 什么会推翻它 |
|---|---|---|---|---|---|
| 扩张 | 哪些变量改善？ | 什么事件标志变化？ | 最先出现什么变化？ | 谁捕获价值？ | 哪项观察会打破逻辑？ |
| 基准 | 哪些变量保持拉扯？ | 什么机制维持均衡？ | 需要持续看什么？ | 谁仍然暴露于风险？ | 什么观察会改变基准情景？ |
| 收缩 | 哪个约束变成瓶颈？ | 什么事件触发收缩？ | 最先恶化什么？ | 谁承担损失？ | 什么复苏信号最重要？ |

## 针对性诊断

完成主张台账后，针对本期播客的具体赛道和商业模式，自行生成 3—5 个针对性的诊断问题，用于检验分析质量。这些问题不写入文档，仅作自查。
