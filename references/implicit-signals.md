# 隐性信号方法论

从说话者的话语中反推表面说法之外的顾虑和真实难题。执行级规则见 SKILL.md 第 6 节，本文件承载内部分析方法。这里的术语用于帮助模型判断，不能原样堆到成品里增加读者负担。

## 内部复杂，成文简单

六维、基线、多信号印证和三档分级全部属于内部工作。读者只需要看到：结论、理由、另一种可能和判断方法。

默认成文格式：

```text
💧 隐性信号 I-01｜一句大白话结论
为什么这么判断：直接引用或忠实转述两处关键说法。
也可能是另一种情况：用普通语言给出最强替代解释。
怎么判断：说明未来看哪个具体数字、动作或结果。
```

标题可以省略“为什么这么判断”，直接用一至两句话讲清理由。禁止在成品中默认使用“显性引导 A”“隐性顾虑 B”“深层指向 C”“反方解释”“可证伪条件”等研究术语。

## 原理：有成本的选择携带信号

任何信号分析的前提：**信号必须来自有成本的选择**。金融中成本是金钱损失（资金用工具选择投票）；话语中成本是**信誉与证伪风险**——说具体了会被证伪，归因错了会被追问，选错参照系会被识破，押注会被事后检验。

因此话语分析的正确姿势：**找话语中"有成本的部分"，这些部分才携带信号**。零成本的模糊话语（"长期来看""大家都在转型"）不携带评估信息，不作推演依据。

## 六维检测框架

从"话语的可检验成本"这一原理导出六个维度，每维对应一种独立的成本形式。六维用作**检测器**（判断是否存在隐性信号），交叉印证与背景信息用作**判定器**（判断信号是什么）。

| 维度 | 可观察特征 | 成本形式 | 解码逻辑 | 检测问题 |
|---|---|---|---|---|
| 1. 选择与省略 | 详略分布：反复强调的 vs 一句话带过的 vs 被岔开的 | 省略有被发现的风险 | 他愿意展开的部分是显性引导 A；被快速滑过的部分是隐性顾虑 B 的所在地——顾虑常藏在详略失衡处 | 哪些话题被反复强调？哪些被一笔带过？哪个问题被岔开或改换话题？ |
| 2. 归因结构 | 成败归因：成功归谁（自己/团队/外部），失败归谁（环境/对手/自己） | 归因可被外部材料比对 | 自利归因偏差。他把哪些事归为"我控制的"、哪些归为"不可控的"——归为不可控的部分暴露掌控感的真实边界，即 B | 成功案例归因于谁？失败归因于谁？他把自己放在因果链的什么位置？ |
| 3. 比较与参照系 | 选什么做参照：和谁比、和哪个时段比、用什么指标衡量 | 参照系可被质疑 | 选"增长率"而非"利润"、选弱势对手而非强势对手——参照系的选择框定了评价标准，暴露他想让你用哪把尺子量，指向 C | 他选了谁做参照？避开了哪个更强势的参照？用什么指标衡量成败？ |
| 4. 情态与确定性 | 语法标记：断言式（"就是""一定"）vs 条件式（"如果"）vs 引用式（"数据显示"）vs 模糊化（"某种程度上"） | 断言可被证伪 | 确定性的语法分布暴露真实信心；高频引用式 = 借权威掩盖不确定。信心最低处就是顾虑最重处，即 B | 断言式表述集中在哪些话题？哪些话题突然转为条件式/引用式/模糊化？ |
| 5. 利益位置与话语功能 | 说话者角色（亲历者/受益者/裁判员），话语在办什么事（邀功/辩护/立标杆/招募/划线） | 利益可被看穿 | 话语是行动不是描述。先问"这句话为他办成了什么事"，再问"为什么需要办这件事"——防御密集处是 B，招募/划线的指向是 C | 这句话为说话者办成了什么事？为什么需要办这件事？ |
| 6. 预言结构 | 预测是否可证伪：具体数字/时点/条件 vs "趋势""长期来看""终将" | 预言可被事后检验 | 押上信誉的具体预言 = 真实信心所在（C 的指向）；拒绝押注的模糊断言 = 留的后路 | 预测是具体可证伪的（数字/时点/条件）还是模糊不可证伪的？他押上了什么信誉？ |

**基线纪律**：维度 1–4 的"异常"判定必须有基线——相对该说话者在本期逐字稿中的通篇表达模式（如通篇断言式、仅此处转模糊化），或知识库中该说话者的历史模式。无基线不判定异常。此条是"禁止无参照判断"在话语分析域的延伸。

## 三档分级判定

| 档 | 判定标准 | 输出 |
|---|---|---|
| `可判定` | ① 六维检测到异常；② 至少两维独立指向同一方向（多信号印证）；③ 关键结构特征已核查为真 | 完整条目 |
| `存在但不可判定` | ① 六维检测到异常；② 无法多信号印证，或各维指向矛盾，或关键背景缺失 | 压缩条目 + 并列候选解读 |
| `无信号` | 六维检测无异常 | 不写、不标注 |

**内部可判定记录格式**：

```
💧 隐性信号（编辑推演）
显性引导 A：他想让你接受的结论
隐性顾虑 B：他在防什么、怕什么被追问（维度 1/2/4 解码）
深层指向 C：他实际在引导的方向（维度 3/5/6 解码）
推演论据：用了哪几维、各自的可观察特征是什么、基线是什么
反方解释：同一证据的竞争性解读
可证伪条件：什么新证据会推翻此推演（检验条件汇入第 7 段监控清单）
```

A/B/C 不齐全时如实写，不硬凑。**强行凑齐 A/B/C 本身就是玄学**。

**内部存在但不可判定记录格式**：

```
💧 隐性信号（编辑推演 · 未判定）
检测到的异常：维度 X 特征（附逐字稿定位）
判定：此处大概率存在隐性信号，但现有语料不足以判定其内容。
候选解读（并列，非结论）：
- 方向 1：……（支撑：维度 X 的某特征）
- 方向 2：……（支撑：维度 Y 的某特征）
要判定缺什么：后续资源投入数据 / 财务披露 / 该说话者的历史归因模式。
```

要点：候选解读必须并列、不选边；每条候选注明由哪一维的什么特征支撑；"缺什么信息才能判定"必须写——这是给读者的真实价值。

## 呈现位置

- 只与一个段落强相关，且会显著改变读者理解的高价值信号：紧跟该段，用短 callout 呈现。
- 需要两个以上段落共同支持的信号：集中放入正文后的“综合推演”，避免打断内容还原。
- 同一信号只完整呈现一次；可证伪条件汇入监控清单时只引用编号，不复制全文。
- 没有足够证据或没有实际阅读价值时不写，不为版式完整强行生成。

## 行为信号子模块（金融三维）

仅当播客中涉及**真实、可查证的资金/公司行为**时启用（自建工厂、签长约、卖出期权、折价大宗等），对话语六维的补充。同一原理（有成本的选择携带信号），成本为金钱损失。

| 维度 | 反推问题 | 示例 |
|---|---|---|
| 收益形状 | 他选的结构排除了哪种收益路径（暴涨/爬升/震荡/下行）？斜率与确定性如何？ | 卖 Put 而非买 Call → 排除"预期暴涨" → 底部确定 + 斜率平缓 |
| 时间立场 | 时间在谁那边？谁在等谁？ | 卖方收时间价值 = 时间在卖方；急售折价 = 时间在追他 |
| 底线位置 | 他把底线划在了哪个具体位置（价位/条款/边界）？ | 行权价、对赌条款边界、ESOP 行权条件 |

**结构特征对照表**（金融语境 → 商业语境）：

| 金融语境 | 商业语境对应物 |
|---|---|
| 期权工具特性 | 合同条款设计（对赌、回购、排他、激励条件） |
| 大宗交易结构 | 交易结构（现金 vs 换股、并购 vs 合资、支付节奏） |
| 尾盘时点/方式 | 时机与节奏（何时宣布、试点 vs 铺开、一次性 vs 分批） |
| 折价幅度 | 定价与折扣结构 |
| 波动率曲面 | 群体指标（行业拥挤度、多公司行为收敛/分化） |

**无信息波动的排除**：机械性、合规性、跟风性动作不携带评估信息（如例行公告、监管要求的调整），识别它们并标注"不携带评估信息"同样是本模块的产出。没有替代方案的选择不携带信号——被迫行为（现金流枯竭下的抛售、监管强制调整）不作推演依据。

## 纪律清单

1. 内部归类为“编辑推演”，对读者统一显示为“隐性信号”，用 callout 呈现，禁止核查颜色——推演层与核查层严格分离。
2. 每条必有反方解释与可证伪条件，缺一不可。
3. 异常判定必有基线，无基线不判定。
4. 推演依据的结构特征先过事实核查（SKILL.md 第 2 节例外）。
5. 术语：推演增强称"多信号印证"，"交叉验证"专指事实核查标签。
6. 语料边界：仅限本期逐字稿 + 公开网络信息 + 知识库 speaker 档案。禁止凭 agent 自身印象推断。
7. `可判定`必须在逐字稿中定位到两处以上独立语言特征；定位不到降档为`存在但不可判定`。
8. 不设置条数、档位比例或最低产量；质量只由证据门槛、反方解释和可证伪性决定。
9. 初稿完成后必须重新扫描完整逐字稿；没有成立的信号也要在成品中明确说明已经扫描，不能因写作阶段未顺手发现就跳过。
10. 成文优先沿用原话，不发明组织、角色或机制名称。需要概括时，先用一句大白话定义其具体所指。

## 案例卡

> ⚠️ 以下案例改写自用户提供的金融信号分析材料。原文为叙事文风、无反方解释；本 skill 执行时反方解释与可证伪条件为必写项，以下案例已补写。原文中"利空出尽""恐慌是底"一类断言不可直接沿用——它们不可证伪，违反本 skill 的证据纪律。

### 标准案例：段永平卖出泡泡玛特看跌期权（Sell Put）

**💧 隐性信号（编辑推演）**

- **显性引导 A**：段永平公开表态看好泡泡玛特，且高调卖出看跌期权，"用真金白银划出价格底线"。
- **隐性顾虑 B**：工具特性暴露其不认为短期会暴涨——若确信一个月内翻倍，理性选择是买正股或买 Call；卖 Put 意味着他排除了"高斜率上涨"的收益路径。
- **深层指向 C**：他的评估是"底部确定 + 缓慢爬升"——收益形状平缓、时间立场在他这边（卖方收取时间价值）、底线位置明确（行权价）。
- **推演论据**：维度 3（参照系）——工具选择本身是参照；排除替代方案（买 Call/正股）后剩余的解释收敛。行为信号子模块三维全部可用：行权价 = 底线位置；卖 Put = 收益形状平缓；收保费 = 时间立场。
- **反方解释**：也可能只是赚波动率保费、不打算真的接货；或该仓位只是其组合中极小的一部分，不具备表态意义。
- **可证伪条件**：若其在行权价附近减持正股、提前平仓或展期，则"愿意接货"的解读被推翻；若仓位金额披露后占组合比例极小，则"划线"解读被削弱。

### 信号类型示例

**1. 折价大宗交易（Block Trade）**

- 显性：大股东资金需求，折价抛售。
- 隐性：接盘机构敢在折价 5–10% 全部吃下，其尽调后的接盘价即专业机构的估值锚点；高管让出筹码可能换取后续业务资源（战略绑定）。
- 反方解释：可能纯粹是资金需求，无任何战略含义；接盘方也可能是被动配置而非尽调后的主动选择。
- 可证伪条件：后续是否出现业务合作、董事会席位变动；锁定期满后接盘方是否抛售。

**2. 尾盘大笔拉升/砸盘**

- 显性：收盘前价格剧烈波动。
- 隐性：无量硬拉多指做市商/基金做净值管理——暴露高杠杆或清算压力，必须把收盘价（保证金与净值基准）拉到安全线以上；尾盘杀跌但全天放量可能只是 ETF 调仓或期权到期日 Delta 对冲，与基本面无关。
- 反方解释：无量硬拉也可能只是自营盘的短期收益曲线管理，与杠杆压力无关。
- 可证伪条件：次日价格是否回落；是否与财报披露日、保证金结算日重合。

**3. 低行权价的股权激励计划（ESOP）**

- 显性：给员工发福利、激励团队。
- 隐性：行权条件定得低（如业绩增长 10% 即可行权）→ 管理层对短期爆发没信心——高速爆发期通常会设定高对赌；行权价即高管团队的"利益底线"。
- 反方解释：低目标可能只是行业惯例、员工谈判结果，或防止核心人员流失的防御性设计，与管理层信心无关。
- 可证伪条件：同期是否出现大额回购、高管增持；后续业绩是否大幅超出该低目标。

**4. 波动率曲面异常（IV Skew，看跌 IV 远高于看涨 IV）**

- 显性：市场买 Put 保险者众，普遍恐惧下跌。
- 隐性：Put IV 至历史极值 = 机构尾部保险买满、做空力量极致拥挤；做市商因收取过高波动率溢价而反向做多正股对冲，预示均值回归力量积聚。
- 反方解释：高 Put IV 可能反映已知的特定事件风险（诉讼、财报、政策窗口），并非整体性恐慌。
- 可证伪条件：特定事件落地后 IV 是否快速回落；正股是否出现做市商对冲买盘。

### 话语六维的应用示例（商业播客语境）

以下为六维在典型商业播客话语中的检测示意：

> 嘉宾："我们从来没把竞品当对手，这个市场大得很。（维度 1/5：回避具体竞争 + 划线）我们 Q3 的增速是整个行业的两倍，这是有权威报告背书的。（维度 3：选"增速"为尺、选行业均值为参照；维度 4：引用式——借权威掩盖不确定性）未来两年我们会达到盈亏平衡——我是说，如果市场环境不出现大的波动的话。（维度 6：具体预言 + 突然附加条件；维度 4：断言式转为条件式）"

六维在此处的读数：详略失衡（不展开竞争话题）、参照系偏袒（选增速不选利润）、情态骤变（断言转条件）、预言留后路——多个独立特征指向同一方向（对盈利前景的确定性低于表面表态），满足`可判定`档的多信号印证门槛。
